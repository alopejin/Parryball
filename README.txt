Instructions for Online Jam/Scored Multiplayer with Noray:

Before trying anything, on Windows, the first time each player opens the game they must click any Join button in the Online Scored or Online Jam menu and enter root password when
Windows asks for it, to prevent the Firewall from rejecting the game's connections.

Then one player clicks Host button and shares the OID code generated automatically when the game runs. Then the other
player must paste it into the OID box (after deleting theirs) and click Join button. Since there are still no notifications on whether the connection
has succeeded or not, it is recommended to run the game through the console to check there if it happened or the 
two attemps to Handshake have failed. If the Handshake succeeds, the Host can press Start button to start the game.

Warnings: 

-The server that handles the Handshake between the players is a free low quality server I created as an alternative to tomfol.io,
meaning it is very unstable and sometimes requires a few tries to succesfully Handshake. The next update will provide an option to choose between the two.

-If the NAT type of either player's network is Symetric NAT (very common on mobile networks), it is very unlikely the Handshake will succeed, so it is 
recommended that both players be connected to local home networks. You can check yor NAT type at sites like https://natchecker.com/

-If the Handshake fails then the game must be restarted to try again, sorry for any inconvenience, I will try to solve this in future updates.


Instructions for LAN Jam/Scored Multiplayer:

Check your local IP with cmd command "ipconfig" on Windows or "ipa"/"ipconfig" on Linux Shell, enter that IP on the LAN Jam menu, 
choose a desired Port (starting at 1000 advised), and click Host button, then the other player must enter same IP and Port and click Join button. 
After the player joins, Host must press Start button.

Windows may ask you for root password in order to allow that connection, which is necessary
otherwise its Firewall will reject it.


Controls for local games:

Player 1:

Move and jump: keys "A", "D" and "W"
Serve: key "E"
Parry: key "E", "T" or left mouse click

Player 2:

Move and jump: keys "left_arrow", "right_arrow" and "up_arrow"
Serve: key "-"
Parry: key "Intro"


Controls for online games:

Move and jump: keys "A", "D" and "W"
Serve: key "E"
Parry: key "E", "T" or left mouse click
